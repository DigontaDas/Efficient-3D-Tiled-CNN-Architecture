# Read-only bug audit

Audit date: 2026-11-07. Scope: source inspection of the clinical engine, primary matched benchmark, unseen-cohort evaluation, five matched training paths and selected historical scripts. Severity means **changes reported numbers** where the code demonstrably computes the wrong quantity or produces a conditional wrong result; **could change them** where occurrence or impact depends on the inputs, run or interpretation; and **hygiene** for reproducibility/portability. A code defect is not proof that a particular published table was produced by that code with the triggering inputs. **NEEDS-LAB-CHECK** marks missing evidence about actual data, execution, provenance, checkpoints and clinical validity. No training or real evaluation was run. Findings are not an exhaustive proof that other scripts are correct.

Two synthetic checks were executed with Python/NumPy/SciPy, without writing test files: extracting the actual primary `_surface_distances` function using Python AST gave 0 mm for a 5³ cube strictly inside a 7³ cube, where the maximum nearest surface distance is 1 mm; the actual report regex returned no match for `Max Stenosis: 64.2%`. The checked-in `splits_final.json` has 690 unique train, 94 unique validation and 150 unique test IDs, with all pairwise intersections empty. This checks IDs in that manifest only.

## 1. Stenosis quantification and post-processing

**S1 — Reference diagnosis influences targeted predictions.** `Phase3_Local_Integration/production_qca_engine.py:171`, `:260`, `:268`, `:416`. Evidence: `tloc = gt_df.loc[cid, 'lesion_location']`; `is_target_patent = ("PATENT" in target_str or "NORMAL" in target_str)`; patent selects longest branch, other labels select maximum stenosis. **Severity: changes reported numbers** when selection differs. This is label/diagnosis leakage, beyond simply using an independently supplied vessel location: changing NORMAL/PATENT changes the selection rule. The numeric radiologist percentage is joined after `process_case`, not directly copied into its output. A report location alone can legitimately define a conditional targeted measurement, but it is not autonomous and diagnostic words must be blinded. Fix: take a prespecified vessel/location-only input stripped of diagnostic terms; predefine one selection rule; separately report blinded autonomous performance. Test: identical synthetic geometry with two branches, vary only `LAD NORMAL` vs `LAD`, and assert the prediction is invariant to diagnosis. **NEEDS-LAB-CHECK:** quantify effect on the reported targeted cohort and whether inputs were available independently at deployment.

**S2 — Unmeasurable geometry becomes a fabricated normal-looking measurement.** `Phase3_Local_Integration/production_qca_engine.py:182`, `:258`. Evidence: `if not branch_evals: best_lesion = {"ds": 10.0, "as": 19.0, ... "artery": "LAD"}`. **Severity: changes reported numbers** for these cases. No valid evaluated branch is not evidence of 10% stenosis or LAD. Fix: return an explicit measurement failure and exclude/report failures under a prespecified analysis, including sensitivity analysis. Test: synthetic geometry with no branches or all diameters under 1.4 mm must return failure, never 10%. **NEEDS-LAB-CHECK:** count affected cases.

**S3 — Anatomical artery mapping ignores image direction and patient anatomy.** `Phase3_Local_Integration/production_qca_engine.py:116`, `:142`. Evidence: `artery = "RCA" if b_x < mid_x else ("LAD" if b_y < mid_y else "LCx")`. Array indices and bounding-box midpoint alone do not identify vessels; NIfTI direction/orientation and individual variation matter. **Severity: could change them**, particularly targeted matching. Fix: use physical coordinates and validated anatomical labeling, or explicitly mark branch identity uncertain and require independent localization. Test: encode the same synthetic anatomy with flipped axis/direction metadata; assignment should stay invariant. **NEEDS-LAB-CHECK:** compare vessel assignments with radiologist annotations.

**S4 — Branch distance calculations use mean voxel size rather than path length.** `Phase3_Local_Integration/production_qca_engine.py:63`, `:90`, `:150`, `:206`. Evidence: graph edges have physical weights, but `length_mm = len(b) * vox_size` and `w_nodes = round(8.0 / vox_size)`, with `vox_size = mean(sp)`. Diagonal steps and anisotropy invalidate both the purported mm length and 8–16 mm reference windows. **Severity: could change them.** Fix: cumulative physical edge lengths along each branch and distance-based window selection. Test: represent equivalent straight and diagonal physical paths on anisotropic grids and verify equal lengths and reference windows.

**S5 — Area percentage is treated as diameter-based clinical grade.** `Phase3_Local_Integration/production_qca_engine.py:241`, `:245`, `:288`, `:344`. Evidence: `get_cad_rads_str(as_pct)` and `y_ai_as - y_rad`, where `y_rad` is radiologist diameter stenosis. Area reduction and diameter reduction are different quantities; the squared-ratio estimate also assumes circular sections. **Severity: changes reported numbers** for the area-bias and area-based grade outputs; those comparisons do not measure like with like. Fix: compare diameter with diameter and area only with independent area references; use diameter-based thresholds for CAD-RADS. Test: diameters 2 and 4 mm yield 50% diameter and 75% area reduction; assert they are not treated as the same grade/reference.

**S6 — Diagnostic heuristics overwrite the geometric percentage.** `Phase3_Local_Integration/production_qca_engine.py:240`. Evidence: for `mld >= 2.8` or shallow notch with `mld >= 2.0`, diameter reduction is multiplied by `0.20` and capped at 15%. **Severity: could change them**; a sufficiently large absolute lumen does not by itself prove a fractional narrowing is non-pathological. Fix: report raw geometric measurement and any separately validated classification with frozen thresholds. Test: a synthetic 6 mm reference and 3 mm minimum must retain its geometric ratio instead of silently being shrunk. **NEEDS-LAB-CHECK:** determine prevalence and independent clinical validation of these heuristics.

## 2. Evaluation and statistics scripts

**E1 — Primary HD95/ASD measures distance to the other volume, not its surface.** `Q1_Publication_Package/matched_200ep_benchmark/evaluate_matched_200ep_models.py:66`, `:74`; same pattern `THESIS_RECOVERY/scripts/02_fair_benchmark_evaluator.py:68`. Evidence: docstring says nearest surface but `distance_transform_edt(~mask_b, sampling=spacing)` is zero anywhere inside mask B. **Severity: changes reported numbers** whenever nested/intersecting surfaces contribute distances; it can bias HD95/ASD downward. Fix: transform the complement of B's extracted surface, then sample at A's surface, with a documented symmetric definition. Test: the executed nested-cube check returned max 0 instead of 1 mm for the inner-to-outer direction; compare both directions with an independent surface-point implementation. **NEEDS-LAB-CHECK:** recompute affected tables from actual masks; no numerical impact is inferred here.

**E2 — Empty masks receive arbitrary and asymmetric boundary scores.** `Q1_Publication_Package/matched_200ep_benchmark/evaluate_matched_200ep_models.py:97`; `3d Cas Validations and doings/scripts/evaluate_unseen_66_models.py:121`, `:166`. Evidence: primary uses `100.0 if not pred_bool.any() else 0.0`; unseen substitutes 15 mm/2.5 mm whenever undefined or calculation fails. Thus nonempty prediction with empty GT gets perfect zero in primary, while both empty get 100, and unseen failures masquerade as measurements. **Severity: changes reported numbers** if triggered. Fix: explicit empty-mask policy, undefined/NaN plus failure counts and sensitivity analysis; never silently replace exceptions. Test all four empty/nonempty combinations and inject a surface computation error. **NEEDS-LAB-CHECK:** count affected cases.

**E3 — Cache validity is inferred from row count only.** `Q1_Publication_Package/matched_200ep_benchmark/evaluate_matched_200ep_models.py:516`. Evidence: `if len(df_exist) == len(test_ids): ... return df_exist`. A different same-size cohort, model checkpoint or settings can reuse old metrics. **Severity: could change them.** Fix: check unique exact case-ID set plus hashes of checkpoint, input masks, metric version and inference parameters; otherwise recompute. Test: cache IDs [1,2] and request [3,4], then assert rejection even though both have two rows. **NEEDS-LAB-CHECK:** establish provenance of each published CSV.

**E4 — Paired testing can pair different patients.** `Q1_Publication_Package/matched_200ep_benchmark/evaluate_matched_200ep_models.py:619`, `:627`. Evidence: both tables are sorted then `wilcoxon(x, y)` is called without checking matching IDs; missing cases are silently skipped at `:535`. Equal-length different sets yield apparently valid but invalid pairs; unequal sizes become p=1 via broad exception. **Severity: could change them.** Fix: validate unique case IDs and identical case sets, or explicitly inner-join and report exclusions before testing; propagate errors. Test: compare IDs [1,2] against [2,3] and require failure, not a p-value. Separate `Q1_Publication_Package/stats/01_significance_testing.py:77` checks matching lists; do not conflate the two scripts.

**E5 — Report text parser silently emits zero for unrecognized reports.** `Q1_Publication_Package/clinical_validation/07_stenosis_agreement.py:59`. Evidence: initialized to `0.0`; regex expects `64.2% stenosis`, despite its example `Max Stenosis: 64.2%`. The executed check produced no match. **Severity: changes reported numbers** when affected reports enter this script. Fix: use structured source records; otherwise support documented formats and fail/NaN when missing, never infer zero. Test both word orders, unrelated percentages, missing values, and duplicate reports. **NEEDS-LAB-CHECK:** whether this older agreement path generated reported clinical results.

**E6 — Pseudo-Dice is presented as comparable validation Dice.** `Q1_Publication_Package/matched_200ep_benchmark/prepare_and_run_nnunet_200ep.py:156`; `Q1_Publication_Package/figures/render_5model_convergence_curves.py:84`, `:101`. Evidence: parser assigns `Pseudo dice` to `val_dice`; plot labels all curves `Validation Dice (DSC)`. **Severity: changes reported numbers/interpretation** in convergence comparisons; nnU-Net's logged pseudo metric is not the same full-volume case-level validation metric used by the other training loops. Fix: label it explicitly and avoid direct comparison, or evaluate all models on the same full volumes each epoch. Test: synthetic patch sampling with uneven foreground demonstrates patch-pooled Dice differs from mean full-volume Dice. **NEEDS-LAB-CHECK:** inspect the actual nnU-Net version/logs and publication figure provenance.

## 3. Data loading, splits, case-ID and series matching

**D1 — Historical training monitors the test set to stop training.** `_Archive_Historical_Experiments_and_Logs/legacy_pre_200ep_scripts/train_and_track_v3.py:222`, `:300`, `:322`, `:328`. Evidence: `evaluate_v3_checkpoint(model, test_ids)` followed by test-Dice and precision stopping conditions. **Severity: changes reported numbers** if that selected checkpoint is reported as held-out; it adaptively selects using test labels. Fix: use validation IDs for all stopping/model selection, then evaluate a locked independent test once. Test: toy epoch scores where test and validation optima differ; assert checkpoint choice remains unchanged when test scores change. **NEEDS-LAB-CHECK:** determine whether this archived checkpoint contributed to any current result; do not assume the matched 200-epoch model did.

**D2 — Targeted DICOM series selection does not establish identity or stable spatial ordering.** `Phase3_Local_Integration/run_hospital_cohort_pipeline.py:229`, `:234`, `:276`, `:288`; `Phase3_Local_Integration/dicom_to_nifti.py:17`. Evidence: groups by `SeriesNumber`, chooses highest heuristic score, sorts only patient z, and the other converter takes `series_ids[0]`. The code never verifies the selected SeriesInstanceUID against a radiologist's series, and multiple studies can reuse SeriesNumber; oblique stacks need ordering along the slice normal. **Severity: could change them.** Fix: group by Study/SeriesInstanceUID, validate geometry and sort by position projected onto the orientation-derived normal, require an explicit verified series mapping. Test: two distinct UIDs sharing series number and oblique slices with identical z must remain separate and ordered. **NEEDS-LAB-CHECK:** compare chosen UIDs and phase with the original hospital studies and annotations.

**D3 — Image and label roots are selected independently.** `Phase3_Local_Integration/dataset_paths.py:42`, `:63`, `:84`. Evidence: `return find_image(case_id), find_label(case_id)`; each searches roots separately. Matching names/IDs alone does not establish matching acquisition or geometry across copies. **Severity: could change them.** Fix: resolve a pair as one manifest entry from a single verified source and validate physical metadata, patient/case identifier and hashes. Test: two roots with crossed incomplete pairs must produce a clear error rather than a mixed pair. **NEEDS-LAB-CHECK:** whether roots contain different versions; this file has pre-existing user modifications.

**D4 — Unseen designation relies on a label, not verified cross-dataset identity.** `3d Cas Validations and doings/scripts/evaluate_unseen_66_models.py:45`. Evidence: `str.contains("QC_Excluded")` selects IDs. The predicate alone establishes exclusion from a particular primary split, not patient independence from all previous training or other named datasets. **Severity: could change them** for an external/unseen claim. Fix: build a versioned patient-level provenance manifest and enforce disjointness against every training/selection dataset using validated crosswalks and duplicate matching. Test: a QC-excluded ID linked to a training patient under another identifier must be rejected. **NEEDS-LAB-CHECK:** original patient/series identities, matching method, all checkpoint training histories, and the separately documented possible test-set tuning of threshold/loss in `FAIR_COMPARISON_PROTOCOL.md:16`. A repository statement of tuning is not execution proof.

## 4. Training scripts for all five models

**T1 — Four matched trainers do not resume optimizer state.** `Q1_Publication_Package/matched_200ep_benchmark/train_rasnet_200ep.py:153`, `:167`, `:268`; `train_segresnet_200ep.py:175`, `:271`; `train_vnet_200ep.py:176`, `:275`; `train_3dunet_200ep.py:160`, `:251` in the same directory. Evidence: last checkpoints save model weights (3D U-Net also epoch/metric), then resume with a newly constructed AdamW and manually advanced scheduler; optimizer moments, scaler and RNG states are not restored. **Severity: could change them** if interrupted/resumed. Fix: atomic checkpoint containing optimizer, scheduler, scaler, epoch, best metric and all RNG states; verify log/checkpoint epoch consistency. Test: deterministic tiny model trained continuously versus interrupted/resumed must have identical next-step parameters. **NEEDS-LAB-CHECK:** whether any published runs resumed and which checkpoints were used.

**T2 — nnU-Net setup can reuse stale inputs and preprocessing.** `Q1_Publication_Package/matched_200ep_benchmark/prepare_and_run_nnunet_200ep.py:54`, `:63`, `:70`, `:203`. Evidence: existing destination files are retained, and preprocessing is skipped if a plans file and any `.npy`/`.npz` exist. It neither validates source contents nor removes extra old cases; missing pairs are skipped while the original IDs are injected into splits. **Severity: could change them** or cause failure. Fix: validate exact case inventory, content hashes and preprocessing configuration; fail for missing pairs and rebuild in a clean versioned directory when changed. Test: prepopulate a stale case or change input for an existing ID and assert setup rejects or rebuilds. **NEEDS-LAB-CHECK:** inspect lab nnU-Net raw/preprocessed inventory and checkpoint provenance.

**T3 — Same seed is not a guarantee of repeatable transforms/resume.** `Q1_Publication_Package/matched_200ep_benchmark/train_rasnet_200ep.py:57`, `:113` (and corresponding SegResNet, V-Net and 3D U-Net trainers). Evidence: seeds Python/NumPy/Torch, while MONAI random transforms and worker RNG state are not explicitly restored for resumed runs. **Severity: hygiene** for reproducibility; stochastic changes can alter trained weights. Fix: configure MONAI determinism and worker seeding, record versions, save/restore RNG and sampler state. Test: run two short CPU synthetic training sessions with the same seed and compare sampled crops and final weights; separately test resume. **NEEDS-LAB-CHECK:** actual library/version and worker behavior.

**T4 — Matched 3D U-Net training and evaluation preprocess differently.** `Q1_Publication_Package/matched_200ep_benchmark/train_3dunet_200ep.py:104`; `Q1_Publication_Package/matched_200ep_benchmark/evaluate_matched_200ep_models.py:266`. Evidence: training resizes raw orientation directly; inference first applies `Orientationd(... axcodes="RAS")` then resizes. The RASNet, SegResNet and V-Net trainers also omit orientation while inference canonicalizes. **Severity: could change them**, depending on original affine orientations and model equivariance. Fix: share a versioned orientation/spacing pipeline between training and inference, or retrain using the intended canonical input. Test: equivalent asymmetric phantom encoded with flipped affine and voxels should have identical canonical model input. **NEEDS-LAB-CHECK:** ImageCAS orientations and the actual transforms used to train each checkpoint. nnU-Net uses its own preprocessing and cannot be assumed to share this mismatch.

## 5. Segmentation inference and post-processing

**I1 — RASNet receives asymmetric benchmark inference.** `Q1_Publication_Package/matched_200ep_benchmark/evaluate_matched_200ep_models.py:436`, `:447`, `:449`; baseline runners at `:228`, `:366`. Evidence: RASNet gets four flip passes, threshold 0.6 and top-two components, while baseline paths use different inference/cleanup. **Severity: changes reported numbers** in the sense that published comparison evaluates pipeline plus architecture, not an isolated architecture effect; magnitude requires rerun. Fix: provide a prespecified equal-inference comparison and clearly separate optimized-pipeline results. Test: stub network outputs with three isolated components and probabilities near 0.6; assert identical settings produce identical postprocessing across models. **NEEDS-LAB-CHECK:** frozen validation-only selection of threshold and actual output provenance.

**I2 — Unseen evaluation cache ignores inference settings.** `3d Cas Validations and doings/scripts/evaluate_unseen_66_models.py:173`, `:178`, `:191`, `:246`. Evidence: output tag incorporates model and optional threshold, but not overlap, dust threshold, checkpoint or code; previously completed IDs are kept. Also default threshold is `0.45` at `:183`, despite descriptions elsewhere using 0.5/0.6. **Severity: could change them.** Fix: fingerprint all settings, preprocessing and checkpoint; reject mismatches; write manifest with every CSV. Test: run a synthetic completed ID with dust threshold 50 then 0 and verify it is recomputed. **NEEDS-LAB-CHECK:** determine command lines and settings behind existing CSVs; do not infer them from filenames.

**I3 — Failures can fall through to stale predictions.** `Q1_Publication_Package/matched_200ep_benchmark/evaluate_matched_200ep_models.py:181`, `:721`, `:725`, `:730`. Evidence: absent best checkpoint falls back to epoch 200, and an inference exception is only warned before metric computation proceeds. Existing predictions/CSV may then be scored despite failure or a different checkpoint. **Severity: could change them.** Fix: fail the model run on missing requested checkpoint or inference errors; require explicit opt-in to last checkpoint and validate prediction manifest. Test: remove a fake best checkpoint while placing old masks/cache in output; assert no metrics are reported as a successful new run.

**I4 — Grid equality is checked by shape alone.** `Q1_Publication_Package/matched_200ep_benchmark/evaluate_matched_200ep_models.py:538`, `:544`. Evidence: resampling to GT happens only if `pred_arr.shape != gt_arr.shape`; equal-shaped images with different origin, spacing or direction are compared voxelwise. **Severity: could change them.** Fix: check full physical geometry (size, origin, spacing, direction) with tolerance and resample or fail. Test: equal-size identical voxel arrays with a one-voxel origin shift must not score as perfectly aligned in physical space. **NEEDS-LAB-CHECK:** inspect actual image and mask metadata.

**I5 — Top-two component pruning can remove true coronary branches.** `Phase3_Local_Integration/run_hospital_cohort_pipeline.py:72`, `:83`; primary benchmark `evaluate_matched_200ep_models.py:449`. Evidence: `valid_components[:2]` and `top2_labels`. Disconnected real branches beyond two components are deleted independent of anatomy. **Severity: could change them** for both segmentation and stenosis. Fix: validate component policy on held-out cases and report retained/deleted volume; avoid assuming two components, or use anatomy-aware pruning. Test: synthetic three disconnected vessels plus noise: preserve all clinically relevant vessels. **NEEDS-LAB-CHECK:** review deleted components and effect on clinical cohort.

## Ranked ten most likely to affect reported results

This is a triage ranking based on direct code reach and potential impact, not an estimate of measured effect; run provenance and data are unverified.

1. **E1:** systematically wrong primary surface-distance definition for overlapping/nested surfaces.
2. **S1:** radiologist diagnosis influences targeted clinical lesion selection.
3. **I1:** asymmetric RASNet inference changes what the main comparison measures.
4. **D1:** historical test-guided stopping, if its selected checkpoint entered a reported result.
5. **T4:** training/inference orientation mismatch, conditional on dataset affines.
6. **I2:** unseen cache/configuration and 0.45 default can silently misidentify a run.
7. **E3:** same-length cohort or changed-model metrics can be reused.
8. **D2:** heuristic DICOM series selection can change the clinical image measured.
9. **S4:** mean-spacing branch windows distort physical QCA measurements.
10. **T1:** incomplete resumption alters weights when training was interrupted.

Before drawing conclusions about actual reported numerical changes, reconstruct each table's exact generating script, arguments, case IDs, checkpoint hash and mask provenance on the lab PC; rerun the relevant corrected measurements against locked references. **NEEDS-LAB-CHECK** applies to all such impact claims.

3. **Archival of Historical & Outside-Scope Scripts (`S1–S6`, `E5`, `D1`, `D2`, `D4`, `I2`)**: All historical evaluation scripts (`evaluate_matched_200ep_models.py`, `evaluate_ablation_suite.py`), Unseen-66 / 3D-CAS scripts, and local hospital QCA scripts (`production_qca_engine.py`, `07_stenosis_agreement.py`) have been moved to `_Archive_Historical_Experiments_and_Logs/thesis_cleanup_2026-11-10/` (`ARCHIVE_INDEX.csv`).
