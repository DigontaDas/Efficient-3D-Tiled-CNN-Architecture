# A research plan for RASNet after the integrity fixes

20 November 2026 · Read-only review of thesis checkout `e2c929f` · Decision for the next lab run

**Choose Prompt 2 Strategy B for the scientific comparison. First fund one small experiment within it.** Train the corrected 16-filter RASNet and its matched controls, find out where it loses annotated coronary length, and test one change that targets that error. My first candidate is to give narrow vessels more representation when drawing training patches. It changes training without adding a layer or a pass at inference. Its value depends on where the missing vessels actually are.

The current evidence supports a compact model with a measurable precision–recall trade-off. It falls short of establishing superior Dice, superior HD95, or Dice non-inferiority after symmetric inference and pruning. A paper worth pursuing would explain **which vessels the compact model recovers, at what false-positive and runtime cost, and whether the improvement transfers to new patients**. The report below gives a decision at each stage, including what to publish if nnU-Net wins.

## 3. Find the source of the recall deficit before changing the model

Use corrected RASNet, SegResNet and native nnU-Net predictions on **Val‑94 only** for development. Save native-space probabilities for a temporary evaluation pass. Freeze a case list before image review, for example 24 patients sampled evenly across training-defined vessel-volume quartiles with a fixed seed. Aggregate quantitative endpoints on all 94. Have a reader blinded to model identity review paired CT overlays, including disagreements in both directions.

1. **Separate threshold effects from pruning.** On the identical probability volume at each τ, score unpruned, top-two and the preregistered seeded filter. For each discarded component record mm³, true-positive and false-positive mm³, reference centerline length lost, and whether a principal tree disappeared. Plot recall versus precision across the shared grid both before and after pruning. Compare recall at common achievable precision levels. A removed 4,000 mm³ component could contain true artery, false positives, or both.
2. **Separate vessel calibre from location.** Skeletonize the reference on a documented physical grid. Estimate local diameter as twice the spacing-aware Euclidean distance to the reference boundary. Measure length-weighted coverage in prespecified bands, for example <2, 2–3, and ≥3 mm, with the annotated lower limit recorded. Audit diameters and bifurcation artifacts on overlays. Define distal anatomically by reader labels or path distance from marked ostia. A narrow proximal stenosis and a distal branch can share a diameter. Count missing trees, short gaps, vein/aorta false positives and label ambiguity separately.
3. **Check the training samples.** The v2 cache stores every foreground voxel and samples a foreground centre uniformly from that list. A thick trunk therefore offers more candidate centres per millimetre of length. Large patches can still contain thin branches. Draw 10,000 deterministic sample centres from training cases and tally both centre calibre and **actual thin-vessel length inside patches**. Measure survival of thin foreground after resampling and at auxiliary target scales. [Cache construction, line 126](Rasnet-v2/src/cache_builder.py) · [Sampler, lines 185–190](Rasnet-v2/src/augmentations.py)

**Decision.** If the recall gap is already present without pruning at common precision, concentrates on verified narrow branches, and the sampler underrepresents their length, run the training experiment below. If pre-pruning coverage is comparable and the loss occurs when genuine disconnected components are dropped, prioritize the existing seeded-filter versus top-two comparison for **both** models. If the difference largely disappears at matched precision, focus the paper on operating-point selection and calibration. If reader review identifies annotation scope as the dominant cause, settle the reference standard before spending on architecture. Each outcome answers a different research question.

## 4. The first new training experiment I would run

**Hypothesis:** Redistributing positive patch centres by vessel calibre will recover narrow annotated coronary segments at matched precision, while preserving whole-volume Dice and one-pass inference cost.

**One change.** Keep the verified F16 architecture, loss, seed, augmentation, patch size, case sampling and total updates fixed. Keep the overall fraction of foreground-centred patches at one third. For the experimental sampler, draw half of those positive centres as usual. For the other half choose one of the available prespecified diameter bands with equal probability, then sample a reference centreline point by physical arc length in that band. Redistribute an empty band’s probability among available bands using a fixed rule. Use training masks only. Apply identical spatial transformations to the image and label. Record achieved fractions, coverage and training overhead. This is a proposed starting design. Uniform centreline sampling is an essential control because it may explain the entire effect.

| Order | Train or compare | What the comparison identifies |
| --- | --- | --- |
| 1 | Corrected RASNet F16, matched F16 SegResNet, native nnU-Net 3D full resolution | The baseline improvement attributable to fixing the recipe, and the new gap to a credible system. Retain the planned gate-off and deep-supervision-off runs when attributing these components. Match heads when isolating gates. |
| 2 | Corrected RASNet + plain centreline sampling, then corrected RASNet + calibre-balanced centreline sampling | Use the same half of positive centres in both controls. This separates placing samples on centrelines from explicitly balancing calibre. No additional topology loss in these runs. |
| 3 | With the selected policy locked, run the same change on SegResNet and, if technically feasible, on nnU-Net. Preserve a stock native nnU-Net row. | If the gain transfers, credit the training method. If RASNet alone appears to benefit, report a paired difference-of-differences with uncertainty before attributing it to architecture. |
| 4 | Run a published tubular-structure comparator under the same data budget, initially on the corrected baseline. Prefer Skeleton Recall Loss. For broader coronary claims add reproduced CAS-Net if feasible. | Tests whether an established method achieves the same benefit. A published score on a different split belongs in related work. [Skeleton Recall Loss, ECCV](https://www.ecva.net/papers/eccv_2024/papers_ECCV/html/9904_ECCV_2024_paper.php) · [CAS-Net paper](https://pubmed.ncbi.nlm.nih.gov/36630869/) |

**Compute sequence.** Use one seed (42) for screening, equal 50-epoch schedules across variants and full Val‑94 inference at the end. Never compare a short candidate against a converged control to select the winner. Advance only one candidate to a fresh or identically scheduled 200-epoch comparison. A 50-epoch cosine schedule reaches its endpoint, so appending 150 epochs to that checkpoint changes the schedule. Use seeds 42, 123, 456 for the decisive RASNet/control/nnU-Net comparisons. The existing matched budget is 250 updates/epoch, effective batch 2, 50,000 updates and 100,000 sampled patches per 200-epoch run. Verify achieved counts after resume. Stage other architectures behind the critical comparisons via an explicit amendment if GPU time is tight. [Study configuration](Rasnet-v2/configs/fair_v2.yaml) · [Pilot training log](Rasnet-v2/logs/pilot2b_rasnet_v2_f16_convbias_cl000/training_log.csv)

**Proposed validation spending rule.** Agree with the supervisor and reader before seeing the new variants. As an engineering screen, advance a candidate with ≥0.010 absolute improvement in thin-band centerline coverage at matched precision versus corrected RASNet, whole-patient mean Dice at least as high, and no increase in complete principal-tree losses. Also require the calibre-balanced variant to improve on plain centreline sampling to retain the more complicated policy. After 200 epochs, pursue the **Dice superiority** manuscript only if the mean validation difference versus the matched native nnU-Net is positive and has the same sign in at least two of three seed pairs. Show all seed effects. These are spending decisions, distinct from the confirmatory test and the clinical importance of an effect. If stage 1 identifies pruning as the dominant mechanism, spend this budget evaluating the filters and keep the classifier weights fixed.

**Novelty bar.** Coronary scale-aware attention, radius-aware coronary tracking, centerline-based topology losses and supervised surface recovery already have published precedents or recent preprints. Simply renaming the sampler or adding clDice would be a weak contribution. A stronger result would show with matched controls that voxel-centred sampling or pruning creates a reproducible calibre-specific failure, that a cheap intervention resolves it, that a simpler alternative falls short, and that independent readers and patients confirm the change. If the plain sampler performs equally well, publish that finding and use the simpler policy. ## 5. What would count as beating nnU-Net fairly?

**Run two comparisons and label each in the abstract.** First, compare under a fixed 200-epoch budget, same training IDs, field of view where applicable, updates, sampled patches, checkpoint policy, and compute accounting. Hold loss and optimizer fixed for within-backbone ablations. Let the native framework keep its own optimizer and preprocessing where these define its system, documenting the differences. Allow each system the same prespecified validation opportunities for model/threshold selection. Second, run a strong native reference with the authors’ recommended training schedule and native inference. Include a feasible residual-encoder preset such as ResEnc M for a broad nnU-Net claim. Specify version, plan, folds, checkpoint, mirroring and postprocessing. Compare single-model to single-model. Report a native ensemble separately with its total cost if used. If resources cover only the short reference, say “200-epoch single-fold nnU-Net v2 on this protocol.” [nnU-Net Revisited](https://papers.miccai.org/miccai-2024/paper/2847_paper.pdf) · [Official residual-encoder presets](https://github.com/MIC-DKFZ/nnUNet/blob/master/documentation/resenc_presets.md) · [Native workflow](https://github.com/MIC-DKFZ/nnUNet/blob/master/documentation/how_to_use_nnunet.md)

**Choose one primary question before external results.** For the stated goal, use mean paired per-patient Dice difference, RASNet minus the named native nnU-Net, on one prespecified independent cohort under a frozen deployment recipe. A two-sided patient-bootstrap 95% CI entirely above zero supports higher mean Dice for that comparison. Agree on a practically useful effect with readers before locking the study. Report actual gain and interval. A joint claim of better Dice **and** HD95 requires a prespecified dual-endpoint rule, including an HD95 difference interval below zero. If choosing a branch-preservation paper instead, designate a reader-defined branch endpoint first and justify the Dice non-inferiority margin independently. The present v2 registration specifies Dice non-inferiority and superiority for other metrics. An amendment is necessary to make Dice superiority primary. [Existing hypotheses, lines 48–55](Rasnet-v2/PREREGISTRATION_V2.md)

**Use the patient as the statistical unit.** Before evaluation, lock one deployable checkpoint per system (for example, the prespecified seed-42 final checkpoint for both) or equivalent equal-size ensembles. For the training robustness analysis, average paired differences across seeds *within each patient* and show seed-specific effects separately. Three seeds on 150 scans yield 150 independent patient units at most. Stage 5 includes a pooled patient–seed analysis, while Phase I loads a canonical checkpoint. Explicitly name which estimate each table reports. Prespecify patient bootstrap (10,000 resamples), CI/test for the same estimand, secondary Holm family, metric directions, exclusions and missing/empty masks. Count a missed nonempty tree as Dice zero. Report empty masks and undefined surface distances by model, alongside a prespecified worst-case sensitivity analysis. Publish every seed, case pairing, denominator, median/IQR and failure count. [Stage 5, lines 54–93](Rasnet-v2/src/stage5_stats_and_efficiency.py) · [External evaluator, lines 195–206](Rasnet-v2/src/stage6_phaseI_clinical.py) · [Surface metrics, lines 43–69](benchmark/metrics.py)

**Size the cohort for the claim.** As an illustration, using the historical Val‑94 paired SD 0.03187, a two-sided 5% paired-mean test with 80% power needs roughly **80 independent patients for a true +0.010 Dice effect**, **319 for +0.005**, or about **0.014 detectable effect at N = 40**. The approximation is `n ≈ ((1.96 + 0.84) × paired_SD / effect)²`, rounded up. Site shift, missing scans, clustering, an HD95 co-primary or greater variance can increase requirements. Re-estimate variability from development data for the frozen method and sensitivity-test higher variances before recruiting. This calculation explains why an observed +0.002 on a small external dataset could be inconclusive.
