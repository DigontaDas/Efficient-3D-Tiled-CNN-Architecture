## Training-validation reference

- RASNet: `Q1_Publication_Package/matched_200ep_benchmark/train_rasnet_200ep.py:124-131,144-150,243-253,265` loads image/label, channel-first, `CropForegroundd` from image, spacing 0.5 mm isotropic (bilinear image, nearest label), clips/scales -100..800 HU to 0..1. No orientation transform. Sliding window 96³, overlap 0.25, `sw_batch_size` from CLI; softmax/argmax; raw state_dict in `rasnet_best.pth`. Constructor `RASNet(spatial_dims=3,in_channels=1,out_channels=2,init_filters=16,dropout_prob=0.1)` from `Phase3_Local_Integration/rasnet_model.py`.
- SegResNet: `train_segresnet_200ep.py:125-132,145-151,246-256,268` in the same directory has the same validation transform, window, overlap and softmax/argmax; raw state_dict `segresnet_best.pt`. Constructor `SegResNet(spatial_dims=3,in_channels=1,out_channels=2,init_filters=16,dropout_prob=0.1)`.
- V-Net: `train_vnet_200ep.py:124-131,144-152,250-260,272` has the same validation transform, window, overlap and softmax/argmax; raw state_dict `vnet_best.pt`. Constructor `VNet(spatial_dims=3,in_channels=1,out_channels=2,act="elu",dropout_prob_down=0.1,dropout_prob_up=(0.1,0.1),bias=True)`.
- 3D U-Net: `train_3dunet_200ep.py:116-122,135-144,151,225-237,248` loads/channel-first, scales -100..800 to 0..1, resizes image and label to 128³ (trilinear/nearest), with no orientation, cropping or spacing transform; direct full resized volume, sigmoid >0.5; best checkpoint dictionary key `model_state_dict`. Constructor `UNet(spatial_dims=3,in_channels=1,out_channels=1,channels=(16,32,64,128,256),strides=(2,2,2,2),num_res_units=2,norm="instance",dropout=0.15)`.
- nnU-Net V2: `prepare_and_run_nnunet_200ep.py:182-186,203-227,248-250` delegates planning/preprocessing and training to nnU-Net `nnUNetTrainer_200epochs`, configuration `3d_fullres`, fold 0. Native plans, dataset metadata, trainer implementation and checkpoint contain the exact network, normalization, target spacing, patch size and mirroring axes; they are not specified in this source. `evaluate_matched_200ep_models.py:469-486` loads `checkpoint_best.pth` through `nnUNetPredictor.initialize_from_trained_model_folder`. ## Existing evaluation paths and differences

The primary `evaluate_matched_200ep_models.py:197-202,266-271,335-340,403-408` applies RAS orientation absent in the four training validations, and the three patch models omit `CropForegroundd`; primary overlap is 0.5 (`:228,366,436`) instead of 0.25. 3D U-Net resizes after orientation and does not apply training's label transform (`:266-299`). RASNet additionally uses flip TTA, threshold 0.6 and top-two components (`:436-455`); baseline outputs are not equivalent. nnU-Net uses its own predictor and best checkpoint (`:469-486`).

`THESIS_RECOVERY/scripts/02_fair_benchmark_evaluator.py:159-161,212-214,251-256,284-296` similarly canonicalizes RAS and omits training crop; 3D U-Net resizes, uses 0.5 overlap and varies mirroring by arm. `Q1_Publication_Package/ablation/evaluate_ablation_suite.py:67-69,100-107` adds RAS orientation, omits crop and uses 0.5 overlap plus optional TTA. External 3D-CAS paths `3d Cas Validations and doings/scripts/04_evaluate_models_3d_cas.py:186-197,240-241` and `evaluate_unseen_66_models.py:173-183,207-229,272-291` vary orientation, spacing, resize, threshold, overlap and dust pruning; these are not evidence of ImageCAS benchmark parity. Other archived evaluation scripts are historical and have not been exhaustively validated; use their actual transform and checkpoint provenance before relying on them. This inventory is not a claim that every historical script has been individually verified.
